CASA GIOLITTI DASHBOARD

1. Estrai lo ZIP.
2. Apri il terminale dentro la cartella.
3. Esegui: pip install -r requirements.txt
4. Esegui: streamlit run app.py

Per pubblicarla online, carica questi tre file in un repository GitHub e collega il repository a Streamlit Community Cloud scegliendo app.py come file principale.
